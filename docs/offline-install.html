۱. آماده‌سازی (با اینترنت)

۱-۱. دانلود ریپازیتوری

ZIP ریپازیتوری را دانلود و در این مسیر extract کنید:

C:\Users\hello hamid\Downloads\mks-ts35-btt-pi-Helix-screen

۱-۲. دانلود بسته‌ها

این کار را روی یک CB1 با همان ایمیج Armbian و متصل به اینترنت انجام دهید:

mkdir ~/ts35-debs && cd ~/ts35-debs
sudo apt-get update
sudo apt-get install --download-only -y device-tree-compiler python3-evdev python3-spidev
cp /var/cache/apt/archives/*.deb .

پوشه‌ی ts35-debs را در این مسیر کامپیوتر کپی کنید:

C:\Users\hello hamid\Downloads\ts35-debs

۱-۳. دانلود HelixScreen

فایل نسخه‌ی arm64 را از صفحه‌ی Releases در C:\Users\hello hamid\Downloads\ ذخیره کنید:

https://github.com/prestonbrown/helixscreen/releases

۲. انتقال به BTT Pi

در PowerShell کامپیوتر اجرا کنید (به‌جای IP آدرس BTT Pi را بنویسید):

cd "C:\Users\hello hamid\Downloads"
scp -r mks-ts35-btt-pi-Helix-screen ts35-debs biqu@IP:/home/biqu/
scp helixscreen-* biqu@IP:/home/biqu/

سپس وارد BTT Pi شوید:

ssh biqu@IP

۳. نصب (روی BTT Pi)

۳-۱. بسته‌ها

sudo dpkg -i /home/biqu/ts35-debs/*.deb

۳-۲. ماژول spidev

sudo modprobe spidev
echo spidev | sudo tee /etc/modules-load.d/ts35-spidev.conf

۳-۳. کپی فایل‌ها

cd /home/biqu/mks-ts35-btt-pi-Helix-screen
sudo mkdir -p /opt/novin3dp-ts35-helix/scripts /opt/novin3dp-ts35-helix/overlay
sudo cp scripts/*.py /opt/novin3dp-ts35-helix/scripts/
sudo cp overlay/ts35_cb1.dts /opt/novin3dp-ts35-helix/overlay/
sudo chmod 755 /opt/novin3dp-ts35-helix/scripts/*.py

۳-۴. بکاپ

mkdir -p /home/biqu/novin3dp-ts35-helix-backups
cp /boot/armbianEnv.txt /home/biqu/printer_data/config/printer.cfg /home/biqu/novin3dp-ts35-helix-backups/

۳-۵. Overlay

dtc -@ -I dts -O dtb -o /tmp/ts35_cb1.dtbo overlay/ts35_cb1.dts
sudo mkdir -p /boot/overlay-user
sudo cp /tmp/ts35_cb1.dtbo /boot/overlay-user/
sudo nano /boot/armbianEnv.txt

در فایل باز شده، ts35_cb1 را به انتهای خط user_overlays= اضافه کنید. اگر این خط وجود ندارد، این خط را بنویسید:

user_overlays=ts35_cb1

۳-۶. غیرفعال‌کردن KlipperScreen

for s in KlipperScreen klipperscreen; do sudo systemctl stop $s; sudo systemctl disable $s; sudo systemctl mask $s; done 2>/dev/null

۳-۷. نصب HelixScreen

فایل /home/biqu/helixscreen-* را طبق راهنمای همان نسخه نصب کنید:

https://github.com/prestonbrown/helixscreen

۳-۸. سرویس تاچ

اگر بیپر ندارید، در خط اول BEEP=0 بگذارید:

BEEP=1
sed -e "s#__TS35_BEEPER_FLAG__#/home/biqu/beeper_enabled#g" -e "s#__TS35_BEEPER_HARDWARE__#$BEEP#g" \
    services/virtual-touch.service | sudo tee /etc/systemd/system/virtual-touch.service >/dev/null
echo 1 > /home/biqu/beeper_enabled
sudo chown -R biqu:biqu /opt/novin3dp-ts35-helix

۳-۹. بیپر (فقط اگر BEEP=1)

sed -e "s#__TS35_USER__#biqu#g" -e "s#__TS35_BEEPER_FLAG__#/home/biqu/beeper_enabled#g" \
    services/beeper-watcher.service | sudo tee /etc/systemd/system/beeper-watcher.service >/dev/null
grep -q '^\[gcode_macro TOGGLE_BEEPER\]' /home/biqu/printer_data/config/printer.cfg || \
    { echo; cat klipper/toggle_beeper.cfg; } >> /home/biqu/printer_data/config/printer.cfg
sudo systemctl enable beeper-watcher.service

۳-۱۰. فعال‌سازی و ری‌استارت

sudo systemctl daemon-reload
sudo systemctl enable virtual-touch.service
sudo reboot

۴. بررسی

ls /dev/spidev0.2
systemctl status virtual-touch.service --no-pager
systemctl status helixscreen --no-pager

اگر تاچ برعکس بود، مقادیر SWAP_XY، INVERT_X و INVERT_Y را در /opt/novin3dp-ts35-helix/scripts/virtual_touch.py تغییر دهید و بعد این دستور را اجرا کنید: sudo systemctl restart virtual-touch
